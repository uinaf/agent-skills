# agent-skills

Stack skills for coding agents, from uinaf. Install the ones a repository
actually uses, in that repository.

| Skill | Use |
|---|---|
| [react-ban-use-effect](skills/react-ban-use-effect/SKILL.md) | Replace direct React `useEffect` calls with clearer patterns, or enforce a no-direct-effect policy |

```sh
npx skills add uinaf/agent-skills --list
npx skills add uinaf/agent-skills --skill react-ban-use-effect
```

Picking skills by stack: `slopskills` in [uinaf/ffss](https://github.com/uinaf/ffss).
